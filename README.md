# Azure Git Practice
This is my Git practice project.
I am learning Git and Azure DevOps.
## Project Objective## Git Areas

1. Working Directory:
   This is where I create and modify my project files.

2. Staging Area:
   This is where I prepare changes using git add
   before committing them.

3. Local Repository:
   This is where Git saves committed changes
   using git commit.

The objective of this project is to practice Git
version control and understand how to manage
project files using Git commands.

I will learn how to track changes, create commits,
and manage branches for Azure DevOps projects.
